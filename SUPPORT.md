# Fylkren support

Use the maintained resources in this order:

1. Read the [documentation portal](docs/README.md), especially the
   [installation and upgrade guide](docs/operations/INSTALLATION_AND_UPGRADES.md)
   and [user manual](docs/administration/USER_MANUAL.md).
2. Search [existing issues](https://github.com/mfuryto/fylkren/issues).
3. Open a structured question or bug report if the subject is safe to discuss
   publicly.

Include the Fylkren version shown in the application, edition, deployment type,
browser or client, the operation attempted, expected behavior, actual behavior
and a correlation ID where available. Sanitize logs before attaching them.

Never use a public support channel for vulnerabilities, credentials, customer
data, personal data or private infrastructure details. Follow the
[security policy](SECURITY.md) for confidential vulnerability reporting.

GitHub Issues do not create a service-level agreement or replace an Enterprise
support agreement. Commercial, licensing and customer-specific operational
support follows the applicable agreement.
