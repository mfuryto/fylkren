# Branding favicon — 2026-09-23

The browser's initial icon link points to the existing public branding-logo endpoint. The client then renders a centered 64×64 PNG from the stored logo, preserving its aspect ratio. The icon is refreshed when branding changes; removing the logo uses a local product-initial fallback. No third-party service or online dependency is involved.

Verification: `pnpm --filter @fylkren/web build` passed; `pnpm --filter @fylkren/web test` passed 22 files and 71 tests; `pnpm check:structure` passed. Unit tests cover square, wide and tall logos plus invalid dimensions. The initial HTML link and update path were code-reviewed. A manual visual check in a deployed browser, including browser-tab caching behavior, remains to be performed after installation.
