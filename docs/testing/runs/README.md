For each run, record:

1. Run ID, date/time, test tool, application commit and version, test-code revision or hash, environment and fixture reset.
2. The exact scenario subset and the concrete synthetic roles, sites and work levels used.
3. For every control, the expected result, observed result, pass/fail state and where the assertion or retained evidence can be found.
4. Every deviation, including a false test expectation, with cause, correction and a clean rerun. Do not erase failed attempts.
5. Explicit exclusions: manual UI, notification delivery, PDF/print, performance or security checks that were not performed.
6. Cleanup of disposable data and the remaining release-gate status.

The test output and source assertions are evidence references, but neither replaces the observed-results table. Keep secrets, passwords, tokens, personal data and operational content out of records. Use synthetic identifiers where they materially help trace a chain. If raw logs were not retained, say so; do not imply they exist.
