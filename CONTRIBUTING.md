# Contributing to Fylkren

Fylkren uses GitHub Issues for non-confidential bug reports, feature requests and
product questions. Search existing issues before opening a new one, then use the
matching structured template. Include the Fylkren version, deployment context,
expected result, actual result and safe reproduction steps.

Do not include credentials, customer information, personal data, private network
details or production logs. Report suspected vulnerabilities through the
[private security process](SECURITY.md).

Fylkren is source-available and does not accept unsolicited external code
contributions or pull requests. A clear issue is still valuable: it lets the
maintainer reproduce the need, preserve product architecture and apply the same
security, localization, documentation and release gates to the correction.

By participating in an issue, keep the discussion factual, respectful and safe
to publish. The maintainer may close reports that cannot be reproduced, are out
of scope, duplicate existing work or require disclosure of protected data.
