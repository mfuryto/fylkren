# Fylkren branding assets

- `fylkren-logo-master.png` is the high-resolution RGBA source.
- `fylkren-logo-github-512.png` is prepared for the GitHub profile and repository.
- `fylkren-logo-web-256.png` is the default installation logo and the upload format used by Appearance settings.

The mark is an abstract representation of organizational directions converging into clear forward movement. It is not intended as a military, heraldic or national symbol.
