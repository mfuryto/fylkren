# Security policy

Fylkren is currently private. Before public release, the maintainers must enable a confidential vulnerability-reporting channel (for example, GitHub private vulnerability reporting) and publish a supported-version policy. Until that channel exists, do not open the repository to the public.

Do not report suspected vulnerabilities through public issues or pull requests. Do not commit real secrets, credentials, personal data, customer data, production addresses or operational backups. Security testing of installations requires the operator's authorization.

The security baseline and verification evidence are documented in the [security test plan](dev-notes/security/SECURITY_TEST_PLAN.md), [threat model](dev-notes/security/SECURITY_THREAT_MODEL.md), [verification record](dev-notes/security/SECURITY_VERIFICATION.md) and [OWASP ASVS matrix](dev-notes/security/ASVS_5.0.0_L2_MATRIX.md).
