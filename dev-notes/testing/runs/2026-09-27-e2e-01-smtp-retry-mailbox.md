Exploratory attempts are not acceptance evidence. The first could not inspect the sink because its HTTP endpoint was bound to container loopback. After binding that endpoint to the container interface while keeping the host publication on loopback, the application completed rejection, pending retry and successful handoff, but the harness treated folded headers and a base64 body as raw text and reported a false missing-message failure. The sink was changed to expose an unfolded subject and decoded body without retaining raw MIME in its inspection response. A subsequent preflight never entered the application because duplicate Chromium port arguments prevented DevTools startup. Correcting only that disposable browser invocation left the freshly reset application fixture unused. The final command above then passed end to end.
