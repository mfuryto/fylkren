## Deviation and correction

The first complete E2E-18 run **failed** while validating an export produced by the application itself. The validator reported that `webhook-subscriptions.created_by_person_id` referred to an ID absent from exported `people`. The subscription endpoint had stored the authentication identity ID as an actor instead of the domain person ID. This was corrected in [WebhookManagementEndpoints.cs](../../../apps/api/DomainEvents/WebhookManagementEndpoints.cs) for both creation and deactivation. After rebuilding the API, a clean complete run passed. A read-only join in the final database found one person matching the synthetic subscription's `created_by_person_id`; package validation also passed. This was an application defect, not an altered test expectation.
